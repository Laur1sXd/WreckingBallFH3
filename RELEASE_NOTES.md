# WreckingBall FH3 v1.0.0

Forza Horizon 3 on Azimuth with FH3 Mod Platform. Close the game and extract the ZIP beside `azimuth.exe`. The mod DLL goes in `fh3-mods`.

## Compatibility

WreckingBall is designed to run alongside other FH3 Mod Platform mods, including [Levilente’s FH3 mods](https://github.com/Levilente?tab=repositories). Install their DLLs and WreckingBall in the same `fh3-mods` folder and use your existing FH3 Mod Platform installation.
